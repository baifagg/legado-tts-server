# 排障指南（用户版）

> 面向「不是开发者」的使用者。需要看代码/日志的深度排查在 [AGENTS.md §6](../AGENTS.md#6-故障目录症状--根因--修复)。
>
> 出任何问题，**先跑这一条**：
> ```bash
> python doctor.py
> ```
> 它会把环境问题指出来，大部分情况照它的「→ 修复」做就行。

---

## 30 秒分诊

按顺序回答三个问题：

### Q1：网页能打开吗？

浏览器访问 `http://127.0.0.1:18760/health`

| 结果 | 说明 | 下一步 |
|---|---|---|
| 显示 `{"ok":true,...}` | 服务活着 | → Q2 |
| 打不开 / 连接被拒 | 服务没起 | 跑 `python run.py`，看终端报错 |
| 显示 `"ok": false` | 服务起了但模型没加载 | 看 `logs/worker_*.log` |

### Q2：手机能打开吗？

手机浏览器访问 `http://<电脑局域网IP>:18760/health`

| 结果 | 说明 | 下一步 |
|---|---|---|
| 能打开 | 网络没问题 | → Q3 |
| 打不开 | 防火墙 / 不同 WiFi | 见下方「手机连不上」 |

查电脑 IP：`python -c "import socket;s=socket.socket(socket.AF_INET,socket.SOCK_DGRAM);s.connect(('8.8.8.8',80));print(s.getsockname()[0])"`

### Q3：能听到声音吗？

在网页控制台点一个音色试听。

| 结果 | 说明 | 下一步 |
|---|---|---|
| 能听 | 服务完全正常 | 问题在 Legado 配置 |
| 听不到 / 报错 | 合成有问题 | 看「合成失败」 |

## 常见问题

### 手机连不上（网页打不开）

**按可能性排序**：

1. **不在同一个 WiFi**（最常见）
   手机看 WiFi 名称，和电脑的是不是同一个。手机用流量的话肯定连不上。

2. **Windows 防火墙拦了**
   第一次启动 `run.py` 时，Windows 会弹窗「是否允许 Python 访问网络」。
   - 点过「取消」→ 现在去「Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙」，
     找到 Python，把「专用」和「公用」都勾上。
   - 找不到 Python → 用管理员 PowerShell 跑：
     ```powershell
     New-NetFirewallRule -DisplayName "Legado TTS 18760" -Direction Inbound -Protocol TCP -LocalPort 18760 -Action Allow -Profile Any
     ```

3. **路由器开了「AP 隔离」**
   有些路由器默认禁止 WiFi 设备互相访问。登录路由器管理页，关掉「AP 隔离 / 客户端隔离」。

4. **IP 变了**
   电脑重启后 IP 可能变。重新跑 `python run.py`，用终端打印的新地址。

5. **电脑休眠了**
   听书时把电脑电源计划设成「从不睡眠」。

### 导入链接粘贴后没反应 / 报错

1. **先在手机浏览器打开那个链接**
   应该看到一大段 JSON 文本（以 `[` 开头）。
   - 打不开 → 是网络问题，见上一条
   - 能打开但 Legado 导入失败 → 链接粘贴不完整，重新复制

2. **确认用的是哪条链接**
   | 链接 | 语速刻度 | 什么时候用 |
   |---|---|---|
   | `/httpTTS-float.json` | 0~2.0（滑块显示 1.5 这种小数） | **多数新版 Legado** |
   | `/httpTTS.json` | 1~100（滑块显示 10、15 这种整数） | 旧版 / 部分分支 |

   导错了会表现为「语速不正常」而不是导入失败。

3. **Legado 的「网络导入」在哪**
   我的 → 朗读引擎 → 右上角三个点 / 菜单 → 网络导入

---

### 语速不对 / 调了没反应

| 现象 | 原因 | 处理 |
|---|---|---|
| 滑块拉到最大还是慢 | 导入了 `/httpTTS.json`（1~100 版）但 App 用小数刻度 | 改用 `/httpTTS-float.json` |
| 滑块 1.0 却是 1.7 倍速 | float 版的 1.0 不等于原速（原速在 0.5 附近） | 正常设计，见 `docs/TUNING.md §5` |
| 调了滑块没变化 | Legado 缓存了同一句音频 | 换一段文字试 |

**float 刻度对照**（0~2.0）：

| 滑块 | 实际倍速 | 感受 |
|---|---|---|
| 0.5 | 1.04× | 约等于原速 |
| 1.0 | 1.67× | 舒适 |
| 1.2 | 1.92× | 常用 |
| 1.5 | 2.31× | 偏快 |
| 1.7 | 2.56× | 很快（但仍清晰） |
| 2.0 | 4.23× | 极限（会牺牲停顿） |

### 听着听着变慢 / 卡顿

按可能性：

1. **电脑在跑别的东西占显卡**
   打开任务管理器看 GPU。浏览器硬件加速、游戏、别的 AI 程序都会抢。
   最狠的情况：机器上还跑着**第二个 TTS 服务**，会把显存挤爆。查：
   ```bash
   nvidia-smi
   ```
   如果看到两个 python 各占 2–6 GB，关掉一个。

2. **句子太长**
   Legado 里「单句长度」调小到 20–30 字，响应更快。

3. **刚改过文本设置**
   缓存失效，头几分钟在重建，属正常。

4. **笔记本降频**
   插上电源，电源模式调「高性能」。

### 某个音色读错字 / 听着别扭

| 现象 | 原因 | 处理 |
|---|---|---|
| 某个字读错音（多音字） | 模型上下文判断错 | 换一个音色试试；或反馈给维护者加词典 |
| 声音发闷 / 有杂音 | 参考音频质量 | 换音色 |
| 读得特别快 / 特别慢 | 该音色的参考音频语速不同 | 正常现象，换音色或调语速 |
| 声音不像描述 | 可能 refs 文件不完整 | 跑 `python doctor.py` 看「参考音色」是否 ✅ |

### 合成失败 / 没声音

```bash
# 1. 看服务端日志最后几行
tail -20 logs/server.log          # Linux/macOS
Get-Content logs\server.log -Tail 20   # Windows

# 2. 看 worker 日志
tail -30 logs/worker_*.log
```

| 日志关键词 | 处理 |
|---|---|
| `CUDA out of memory` | 关掉其他占显存的程序，见「听着听着变慢」 |
| `音色清单不存在` / `参考音频不存在` | `refs/` 目录不完整，重新拉仓库 |
| `模型未加载` | 跑 `python doctor.py` 看模型文件 |
| `ffmpeg 变速失败` | `pip install imageio-ffmpeg` |

---

### 想换端口 / 局域网有冲突

```bash
python run.py --port 18860
```

主服务会起在 18860，worker 自动用 18870。导入链接也要改成新端口。

---

### 怎么彻底重装

```bash
# 保留模型，只重装依赖
rm -rf .venv            # Windows: Remove-Item .venv -Recurse -Force
python install.py --skip-model

# 连模型一起重下
rm -rf .venv models
python install.py
```
