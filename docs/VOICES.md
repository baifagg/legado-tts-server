# 音色清单

> 20 个中文音色。**男声 10 + 女声 10**，覆盖 107–287 Hz 的基频范围。
>
> 怎么选：先看「适合」列找题材，再试听两三个定下来。听完觉得哪个不对，换一个就行 —— 音色对听感的影响远大于参数。

| 你在听什么 | 首选 | 备选 |
|---|---|---|
| **玄幻 / 修仙 / 武侠** | 男评书 | 老宋、秦川 |
| **历史 / 传记 / 年代** | 男老年 / 女老年 | 老宋、叶澜 |
| **都市 / 职场 / 现实** | 男中年 / 程越 | 王宝、许南 |
| **悬疑 / 推理 / 刑侦** | 陆明 | 男老年（反派感） |
| **言情 / 甜宠** | 林清 / 许南 | 沈约、温言 |
| **家庭 / 亲情 / 催泪** | 女中年 / 温言 | 叶澜 |
| **儿童 / 童话 / 故事会** | 苏禾 | 女评书 |
| **严肃文学 / 名著** | 顾川 | 男老年 |
| **新闻 / 说明文 / 非虚构** | 王宝 | 程越 |
| **对白多的书（想分角色）** | 叙述用 王宝，对白用 沈约/小满类 | 需要 Legado 里建多个朗读引擎手动切 |

> ⚠️ **对白分角色目前要手动切**：Legado 一次只能用一套朗读引擎。要"叙述一个音色、对白一个音色"，
> 得在 App 里建两条引擎，听的时候手动切换。服务端暂不支持按文本自动切换。

## 音色之间的差异有多大

同性别内的音色距离（log-mel 距离，越小越像）：

**男声**关键对比：

| 对比 | 距离 | 听感 |
|---|---|---|
| 王宝 ↔ 云松 | 0.96 | 略像（都是播报腔） |
| 老宋 ↔ 顾川 | 0.64 | **很像** |
| 秦川 ↔ 王宝 | 1.20 | 明显不同（107 vs 146 Hz） |
| 男评书 ↔ 王宝 | — | 起伏差异极大 |

**女声**关键对比：

| 对比 | 距离 | 听感 |
|---|---|---|
| 沈约 ↔ 林清 | 1.11 | 略像 |
| 林清 ↔ 白露 | 1.10 | 略像 |
| 温言 ↔ 苏禾 | — | 明显不同（200 vs 267 Hz） |

**建议**：不用全试。按题材选 2–3 个备选，听一段就能定。

## 想加自己的音色

1. 录一段 **3–10 秒**、安静无背景音、正常语速的中文
2. 把原文逐字打出来（**必须一字不差**，包括"的/了"）
3. 转成 **24 kHz 单声道 WAV**，峰值归一化到 0.84：
   ```bash
   ffmpeg -i 我的录音.m4a -ar 24000 -ac 1 -filter:a "volume=..." refs/我的音色.wav
   ```
4. 在 `refs/manifest.json` 加一条：
   ```json
   {
     "key": "我的音色",
     "label": "我的音色",
     "desc": "男 · 自定义",
     "usage": "自己录的",
     "file": "我的音色.wav",
     "text": "这里放逐字的原文",
     "seconds": 6.2,
     "source": "self"
   }
   ```
5. **校验**（关键）：用 ASR 回读你录的音频，和 `text` 比对，必须 **CER = 0**。
   不一致就说明文本打错了，克隆会失真。
6. 重启服务。新音色会出现在 `/api/voices` 和导入 JSON 里。

详细校验脚本见 [AGENTS.md §7.3](../AGENTS.md#73-换参考音频的额外校验)。

## 音色是怎么来的

| 来源 | 数量 | 说明 |
|---|---|---|
| **AISHELL-3**（Apache-2.0） | 14 | 开源中文多说话人语料，新闻朗读。音质干净、可再分发 |
| **voice-design 生成** | 6 | AISHELL-3 里没有"中年/老年/评书"气质（218 个说话人里 41 岁以上男声只有 1 个），用 OmniVoice 的 `instruct` 生成后存为参考音频 |

**voice-design 的重要限制**：`instruct` 与克隆**不能叠加**。实测给现有音色加 `elderly` 标签，
F0 从 111.4 只变到 109.3（几乎无效），有的音色甚至方向反了。
源码里 `voice_clone_prompt` 优先级更高，`instruct` 被忽略。
所以新增年龄/气质音色只能走「纯 voice-design 生成 → 存为参考音频」这条路。

许可：AISHELL-3 部分 Apache-2.0；voice-design 生成的 6 个属于 OmniVoice 输出，随模型 **CC-BY-NC** 约束。
详见 [NOTICE](../NOTICE)。
